# 《补天序》· IP能力设定总纲（最终修订版）

> **适用范围**：小说能力设定 / 游戏技能树 / 动画战斗体系 / 角色面板 / 剧本战斗描写
>
> **文档版本**：v3.0 · 最终修订版
>
> **核心修正**：律法与属性为**组合关系**，非固定绑定；属性与元素为**显化关系**，非等同关系。


能力由三个独立维度共同构成，每个维度回答一个核心问题：

| 维度     | 核心问题       | 定义           | 类比       |
| :----- | :--------- | :----------- | :------- |
| **律法** | 凭什么能操控？    | 权柄来源与运作规则    | 法律（管合法性） |
| **属性** | 能量长什么样？    | 间隙粒子的宏观结构相态  | 材料（管质地）  |
| **元素** | 在世界上表现为什么？ | 属性在物质世界的具体显化 | 产品（管形态）  |


**属性是间隙粒子的宏观结构相态，是能量的"材料性状"。所有显性能力的能量结构，都必须归入以下六种属性之一。**

| 编号  | 属性名 | 核心  | 配色     | 底层结构    | 基础性状   | 克制  |
| :-: | :-: | :-: | :----- | :------ | :----- | :-: |
| A1  |  炽  |  爆  | 赤红/橙黄  | 高能无序震荡  | 热/快/狂暴 | 克壁  |
| A2  |  噬  |  蚀  | 暗紫/墨绿  | 螺旋侵蚀链   | 蚀/腐/慢  | 克衍  |
| A3  |  壁  |  御  | 琥珀金/岩灰 | 紧密六角晶格  | 硬/重/稳  | 克彻  |
| A4  |  彻  |  穿  | 电光青/白  | 线性定向排列  | 锐/快/聚  | 克溟  |
| A5  |  溟  |  寂  | 深蓝黑/银灰 | 内坍缩球壳   | 冷/静/稀  | 克噬  |
| A6  |  衍  |  生  | 翠绿/淡粉  | 自复制分支结构 | 活/柔/蔓  | 克炽  |

### 4.1 属性的作用

| 属性管什么 | 不管什么 |
| :--- | :--- |
| ✅ 能量的底层结构（震荡/晶格/分支/螺旋/坍缩/线性） | ❌ 凭什么发动（那是律法管的） |
| ✅ 能量的基础性状（热/冷/硬/锐/蚀/生） | ❌ 显化成什么元素（那是元素管的） |
| ✅ 克制关系（属性克制环） | |
| ✅ 视觉/感官标签（颜色、光效、声音、触感） | |
| ✅ 未显化时的纯能量形态 | |


**核心规则：任何属性都可以被任何显性律法驱动（因果律除外）。**

同一属性 × 不同律法 = 不同风味的效果。律法提供"规则"，属性提供"材料"，两者组合决定能力的基本框架。

属性与元素的关系规则

| 规则 | 说明 |
| :--- | :--- |
| 属性≠元素 | "炽"不是"火"，"炽"是火相结构，"火焰"是炽的显化方式之一 |
| 一属性可显化多种元素 | 炽可显化为火焰、熔岩、热浪、光爆等 |
| 一元素可被多种属性驱动 | "火焰"可以被献祭律+炽（烈焰）、污染律+炽（毒火）、精神律+炽（心火） |
| 元素修炼需后天学习 | 觉醒属性≠自动掌握所有元素，需要练习显化 |


**克制环：炽 → 壁 → 彻 → 溟 → 噬 → 衍 → 炽**

| 攻击方 | 克制 | 被克方 | 逻辑 |
| :--- | :--- | :--- | :--- |
| 炽 | → | 壁 | 高温熔化固化壁垒 |
| 壁 | → | 彻 | 坚固屏障阻挡贯穿 |
| 彻 | → | 溟 | 贯穿撕裂寂静虚空 |
| 溟 | → | 噬 | 沉寂冻结侵蚀蔓延 |
| 噬 | → | 衍 | 腐败瓦解生机秩序 |
| 衍 | → | 炽 | 生命滋生中和狂暴释放 |

**克制效果（数值基准）：**

- 属性克制：伤害 +30%，效果成功率 +30%
- 属性被克：伤害 -30%，效果成功率 -30%
- 属性对等：正常判定


| 属性攻击 | 附加异常 | 异常效果 | 被谁克制 |
| :---: | :---: | :--- | :---: |
| 炽 | 灼烧 | 持续HP流失 | 衍（净化） |
| 噬 | 虚弱 | 攻防属性下降 | 溟（冻结） |
| 壁 | 禁锢 | 减速/无法位移 | 炽（熔解） |
| 彻 | 穿刺标记 | 受伤加深 | 壁（抵挡） |
| 溟 | 失魂 | 沉默/无法释放能力 | 彻（刺破） |
| 衍 | 寄生种子 | 持续汲取给施法者 | 噬（腐蚀） |

**异常克制触发：**

- 用克制属性攻击时，可立即解除被克制方身上的对应异常状态
- 属性克制与异常克制同时触发时，进入 **"绝对克制"** ——伤害翻倍，异常必中


**权柄克制链：**

因果律（隐性·不主动干涉）
        ↓
彼岸律 ←==→ 虚无律（对等互克）
        ↓
献祭律 → 污染律 → 血脉律 → 信仰律 → 精神律 → 献祭律

**规则说明：**

- 高阶律法对低阶律法拥有 **"权柄压制"** ——效果不可被低阶律法完全抵消
- 彼岸与虚无为 **对等互克** ——谁先出手谁占优
- 因果律对所有律法有 **绝对优先级** ——但它本身不主动干涉，只设定边界


| 属性关系 | 权柄关系 | 结果 |
| :---: | :---: | :--- |
| ✅ 克制 | ✅ 克制 | **绝对支配**（伤害×3，效果不可抵抗） |
| ✅ 克制 | ❌ 被克 | **属性优势**（+30%，权柄劣势部分抵消） |
| ❌ 被克 | ✅ 克制 | **权柄逆转**（-30%，但可突破属性限制） |
| ❌ 被克 | ❌ 被克 | **绝对劣势**（×0.3，极大概率失败） |
| 对等 | 对等 | **纯粹对决**（仅凭修为与技巧） |



**超凡者不能随意操控任意属性。觉醒什么属性，由以下因素共同决定：**

| 判定维度           | 说明        | 权重建议 |
| :------------- | :-------- | :--- |
| **天生体质**       | 灵魂结构的先天倾向 | 高    |
| **修行途径（Path）** | 走的是什么途径   | 中    |
| **觉醒环境**       | 在什么条件下觉醒  | 中    |
| **随机因素**       | 存在"奇迹觉醒"  | 低    |

| 情况 | 占比 | 规则 |
| :--- | :---: | :--- |
| 单属性觉醒 | 90% | 最常见，一生只能操控一种属性 |
| 双属性觉醒 | 9% | 稀有，需天生灵魂结构复杂或特殊途径 |
| 三属性及以上 | 1% | 极其罕见，通常与"补天规则"直接相关 |
| 全属性 | ≈0% | 理论存在，可能只有"补天者"级别 |

| 方式      | 条件                 |    难度    |
| :------ | :----------------- | :------: |
| 天生双/多属性 | 无需额外条件，需分别修炼       | 低（觉醒时已定） |
| 后天开拓    | 极高修为，通常只能开拓"相邻"属性  |    极高    |
| 律法拓印    | 必须走特定律法（如血脉律），消耗巨大 |    高     |

**相邻属性开拓路径：** 炽 ↔ 衍 ↔ 噬 ↔ 溟 ↔ 彻 ↔ 壁 ↔ 炽

## 十二、设计守则

### 守则一：所有能力必须归属至少一条根律

不可出现"无根律驱动"的能力。若由多条根律混合驱动，必须标注主次。

### 守则二：所有能力必须显现至少一种属性

因果律驱动的能力除外（无相）。若同时显现多种属性，须标注主属性。

### 守则三：所有能力的克制关系必须遵循本规范

- 属性克制：严格按 **炽 → 壁 → 彻 → 溟 → 噬 → 衍 → 炽** 循环
- 权柄克制：严格按 **因果 > 彼岸 <==> 虚无 > 献祭 > 污染 > 血脉 > 信仰 > 精神 > 献祭** 循环
- 不得自行创造例外克制

### 守则四：律法与属性是组合关系，非固定绑定

- 同一律法可驱动不同属性 → 呈现不同风味
- 同一属性可被不同律法驱动 → 呈现不同机制
- 设计能力时，先定律法，再选属性，组合产生效果

### 守则五：属性与元素是显化关系，非等同关系

- "炽"不等于"火"，"炽"是火相结构，"火焰"是炽的显化
- 设计元素时，需基于属性结构推导，不可随意跨属性

### 守则六：三才定位决定作用边界

- **天**属性能力：作用于概念、法则、抽象——不可直接改变物质
- **地**属性能力：作用于物质、能量——不可直接影响灵魂
- **人**属性能力：作用于生命、灵魂——不可直接修改法则
