# 07 · 孵化机制与创作守则

> 这一份回答"IP 生态"的落地方式：**怎么从这个核心，孵出小说、漫画、动画、游戏，最终长成米哈游式的 IP 生态圈。**

---

## 一、核心洞察：你已经有"米哈游式结构"了

米哈游的成功结构是 **"一个宇宙，多产品"**：崩坏、原神、星穹铁道共享一个"虚数之树/崩坏"宇宙，但每款是自洽的世界、自己的主题、自己的主角团。

而彼岸宇宙的**"一元到十方"数理体系，天然就是这个结构的蓝图**：

```
彼岸宇宙 = 零点星（主世界） + 九方（待开发的九个世界）
```

- **零点星** = 主世界（亚细亚州 / 亚瓦兰多大陆），承载当前主角团（云绍、陈天、阿显…）与主线。
- **其余九方** = 未来各产品线的"容器"——每一"方"可以是一个独立游戏/动画的舞台，各自有主题，但**共享间隙粒子 + 八根律 + 位/渡/代价**的底层。

> 所以"世界观核心"这个文件夹，本质就是**跨产品的通用引擎**；每个产品只是"选一个方、选一条律、选一组母题冲突"。

---

## 二、孵化公式（从核心 → 一个作品）

每孵化一个作品，按五步走：

1. **选一个"方"**：零点星，或九方之一（每方对应一个主题倾向，见 [[03-力量体系总纲#五、数理体系（一元到十方）]] 的"十方"表）。
2. **选一条律法做主切口**：八根律每条都有独立哲学，可各成一个故事/阵营/玩法（见下表）。
3. **定主角的"位 / 渡 / 代价"**：用 [[02-母题与核心冲突#六、给创作者的一句话]] 三问框定人设。
4. **选属性 + 元素**：从 [[属性 - 补天序]] 的矩阵里给主角/反派配能力，克制关系即战斗逻辑。
5. **立誓言 / 立代价**：心之锁系的角色必有誓言锚点；献祭律系的必有代价——没有代价的故事，不属于彼岸宇宙。

### 八根律 = 八条"产品主题"（每律一个切口）

| 律法 | 适合的故事主题 | 适合的玩法机制（示例） |
| :-- | :-- | :-- |
| 因果律 | 宿命、时间、不可逆 | 存档/回溯/蝴蝶效应（代价：被罚） |
| 彼岸律 | 存在、位置、重建现实 | 空间重构/地形改造 |
| 虚无律 | 消解、遗忘、概念抹除 | 删除/消除类机制 |
| 精神律 | 意志、认知、幻觉 | 心灵操控/精神对抗 |
| 信仰律 | 信念、纯度、神与信徒 | 信仰值/纯度系统 |
| 献祭律 | 等价交换、取舍 | 献祭换爆发（高代价高回报） |
| 血脉律 | 传承、溯源、家族 | 血脉树/继承技 |
| 污染律 | 同化、异变、侵蚀 | 感染/变异/阵营转化 |

## 三、产品线规划（米哈游式，分三阶段）

| 阶段 | 目标 | 形态 | 关键动作 |
| :-- | :-- | :-- | :-- |
| **阶段一（0→1）** | 立魂、聚核粉 | 高质量短篇/漫画/动态漫 | 用《鱼、潮水、和二人组》这样的单元故事，先立住"位/渡/代价"的魂；主角团（云绍/陈天/阿显/白/孑）落地 |
| **阶段二（1→N）** | 破圈、验证玩法 | 一款小体量游戏（卡牌/战棋/文字冒险） | 直接复用"八根律+六属性+克制"做战斗数值，复用"律法排斥性"做卡组/阵营 |
| **阶段三（N→∞）** | 生态化 | 主产品（动画/开放世界）+ 多衍生产品 | 用"十方世界"扩张：每方一个产品，共享宇宙 |

> 节奏建议：**别一上来做开放世界**（那是阶段三的终局）。先靠"一篇好故事 + 一个把规则感做出来"的小游戏，验证"位/渡/代价"这个魂能不能打动人。

---

## 四、创作守则（新增能力/设定必须遵守）

1. **母题守则**：任何新故事，必须能回答"位/渡/代价"三问；答不上的，不是彼岸宇宙的故事。
2. **公理守则**：不推翻五大公理，不修改 59.27% 阈值。
3. **律法守则**：所有能力必须归属八根律之一（多律混合须标主次）；一个生灵同时只能兼容一个律法。
4. **属性守则**：所有显性能力必须显现一种属性（因果律除外）；克制严格按"炽→壁→彻→溟→噬→衍→炽"。
5. **组合守则**：先定律法，再选属性，元素靠后天学习显化。
6. **代价守则**：凡"渡"必有"代价"；没有代价的强力，违反母题。
7. **术语守则**：以 [[01-底层公理与术语规范]] 为唯一口径，新术语先在此登记。

## 六、版本化与协作

- 沿用 [[版本更新规则]]：动母题/公理 = x（大版本），动力量体系/地图 = y（小版本），补细节 = z（补丁）。
- 建议在本文件夹设一个 `CHANGELOG.md`，每次大改记录"为什么改"，避免团队之间打架。
- 冲突裁决：**母题 > 公理 > 力量体系 > 地图/物种 > 角色**——越靠前的越不能动。
