# 01 · 底层公理与术语规范

> 这一层是世界的"物理定律"。**公理不可推翻**，只可在其之上做文章。故事可以挑战角色，不能挑战公理。

---

## 一、五大公理（权威版）

| 公理 | 内容 |
| :-- | :-- |
| **公理一：间隙粒子** | 宇宙中存在一种基本粒子——[[间隙粒子（Interstitial Particle）]]，比原子更小，无处不在，能进入并影响其他基本粒子。它是所有超凡力量的**唯一**根源。 |
| **公理二：虚能** | 间隙粒子按特定模式排列时，产生一种可被利用的能量——**虚能**。 |
| **公理三：补天者与补天规则** | 历史上存在过一些生灵，穷尽一生研究间隙粒子的排列方式，最终在**死亡时**把自己的排列模式"固定"下来留在零点星。这种模式及其影响/现象，统称为[[补天规则]]。 |
| **公理四：兼容性** | 生命体与间隙粒子之间存在[[兼容性]]。兼容性越高，越能主动排列间隙粒子、产生并操控更强的虚能。 |
| **公理五：律法的排斥性** | 一个生灵**同一时间只能兼容一个律法**。 |

> **推论（重要）**：力量 = 间隙粒子（材料）× 排列模式（规则）× 兼容性（资格）。三者缺一不可。这就是为什么"凡人"和"觉醒者"之间不是量的差距，而是**有没有资格**的差距。

## 二、觉醒阈值（硬规则）

[[觉醒条件]]中已定死，此处收录为公理级常数：

- 生灵的意识能反向影响灵魂中的间隙粒子，当该影响占比达到 **59.27%**（意识-灵魂映射率），灵魂开始产生[[精神力]]，意识得以通过灵魂操纵间隙粒子——即**觉醒**。
- 59.27% 取自真实物理的**渗流模型**（percolation threshold）。这是本世界观"伪科学底座"的标志性细节，对外宣传时是很好的记忆点。

## 三、术语规范（消除内部冲突）

当前库中存在术语打架，**以下为唯一权威口径**：

### 1. "八大根律" vs "七大律法"

- **权威写法：八根律 = 因果律（隐性·无相）+ 七显性律法。**
- 七显性律法 = 彼岸律、虚无律、精神律、信仰律、献祭律、血脉律、污染律。
- 日常口语可用"七大律法"，但**特指七显性律法**；正式文档一律写"八根律 / 七显性律法"。
- 需要回改的文件：[[可公开世界观设定 v1.0.1]]、[[超凡途径——七大律法]] 中"七大律法"列了八个名字的地方，应改为"七显性律法（另有隐性的因果律，合称八根律）"。

### 2. "零点星" vs "彼岸宇宙"

- **彼岸宇宙** = 整个宇宙（含"十方世界"，见 [[03-力量体系总纲#数理体系]]）。
- **零点星** = 当前所有故事发生的主星（亚细亚州 / 亚瓦兰多大陆所在）。
- 关系：零点星是彼岸宇宙中的"主世界"，补天规则固化在零点星。

### 3. "律法 / 属性 / 元素"

- 三者是**三个独立维度**，不是同义词。权威定义见 [[03-力量体系总纲]] 与 [[属性 - 补天序]]。
- 简记：**律法管"凭什么"，属性管"长什么样"，元素管"表现成什么"。**

### 4. 其他高频词

| 词 | 权威含义 |
| :-- | :-- |
| 觉醒者 | 已越过 59.27% 阈值、产生精神力的生灵（含凡人到超凡的起点） |
| 超凡者 | 觉醒后站稳脚跟、有自己律法理解的存在（详见 [[04-境界与成长曲线]]） |
| 补天者 | 兼容性 51–95%、触摸补天规则的至强者；死后其排列模式固化即"补天规则" |
| 君者 | 兼容性 95%+、拥有称号的存在 |
| 位格 | 在世界中的"权重/影响力"，高者能力优先度更高，但在因果律中更显眼、更易被罚 |
| 生命层次 | 接近"神"的程度（寿命、能力强度等），与位格**不绑定**（例：牛顿位格极高、生命层次极低） |
| 意识体 | 由执念驱动、纯灵魂结构的高兼容性生命形态（[[意识体]]） |
| 遗物 | 使用者生前以虚能长期侵染、死后效果有概率保留的物品（[[遗物]]） |
