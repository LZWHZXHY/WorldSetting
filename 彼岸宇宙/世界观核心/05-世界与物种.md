## 一、世界地图（骨架）

```
彼岸宇宙（十方世界）
 └─ 零点星（主星，当前所有故事发生地）
     ├─ 亚细亚州（东）
     │    └─ 九州：修行法体系（命修九炼/阴阳五行决/盘古九变诀）、宗门·世家·皇朝、心之锁（人类专属）
     │
     └─ 亚瓦兰多大陆（西·西州）
          └─ 魔法体系（献祭律衍生·宗教魔法）、多物种混居、冒险者公会
               城市：岚陆奥斯 / 海姆帝国 / 帝都 / 费伦德 / 绯红城 / 斯特罗城（六城，多数待补）
```

**东西差异（世界观级的张力）**：
- 九州 = **秩序 / 传承 / 资质**（修仙，功法被宗门世家把持，普通百姓只碰得到前三炼）。
- 西州 = **自由 / 混乱 / 多元**（多物种、冒险者、公会、宗教魔法）。

> 这一东西对立，天然是"位"（九州的重规守序）vs"渡"（西州的自由出走）的地理投影——[[陈天]]从九州逃到西州，就是这套张力的具体化。

## 三、五大物种（权威核心）

### 1. 人类 —— 心之锁（Chain of Humanitas）

- **天赋能力**：[[心之锁]]，唯一唯心理想主义的力量体系、唯一能主动操作自身灵魂的能力。
- **觉醒三要素**：困境（精神剧烈波动）+ 突破（直面困境并成长）+ 誓言锚点（立誓，违誓则倾覆）。
- **代价与暗面**：觉醒者必有缺陷（面瘫/痛觉缺失等）；违背誓言或强行催动会**腐化→沉沦者**。
- **内核**：人性本性、溯源——探讨人的善与恶，是"渡"母题最纯粹的力量形态。
- **数量**：觉醒者极稀少。

### 2. 精灵 —— 万物之声

- **天赋能力**：万物之声（与自然/万物的共鸣，具体规则待展开）。
- 短篇中的"极光"是精灵（长耳、额颈绿色荧光纹路、无需咏唱施法）。

### 3. 妖族 —— 种族天赋

- **天赋能力**：种族天赋（按种族分化，具体待展开）。

### 4. 矮人 —— （待设定）

- 目前完全空白，建议沿"工匠/锻造/遗物"方向设定，与[[遗物]]体系挂钩。

### 5. 意识体 —— 执念成灵

- 由"执念"驱动、纯灵魂结构、高兼容性生命（[[意识体]]）。
- 诞生：执念成灵（死亡时灵魂卡住重组）/ 修炼转化（主动弃肉体，极危险）。
- **关键**：只能在虚能密度高的区域诞生；部分意识体可能是"未完全固化"的补天者——它们活着，但没死，所以排列模式没固化进虚能场。
- 这是"神/使徒/补天者"之间最关键的**生物学桥梁**，建议作为长线主线的重要设定。
