# 03 · 力量体系总纲

> 力量体系是"规则感"的核心，也是游戏化 / 数值化的地基。本文件是 [[属性 - 补天序]] 的权威精简版 + 数理体系，完整矩阵以补天序为准。

---

## 一、三大维度（先记住这张表）

| 维度 | 核心问题 | 定义 | 类比 |
| :-- | :-- | :-- | :-- |
| **律法** | 凭什么能操控？ | 权柄来源与运作规则 | 法律（管合法性） |
| **属性** | 能量长什么样？ | 间隙粒子的宏观结构相态 | 材料（管质地） |
| **元素** | 在世界上表现为什么？ | 属性在物质世界的具体显化 | 产品（管形态） |

> 守则：**先定律法，再选属性，组合产生效果；元素是属性的显化，需后天学习。**
> 任何属性都可被任何显性律法驱动（因果律除外，无相）。

---

## 二、八根律（权威总表）

| 律法 | 核心逻辑 | 本质 | 一句话规则 |
| :-- | :-- | :-- | :-- |
| **因果律**（隐性·无相） | 万事皆有因，万果皆有源 | 宇宙的底层文法 | 一切被见证的内容必定发生；修改已发生的过去会被罚；因果链越老越难改 |
| **彼岸律** | 万物皆有其位，现实自有其形 | 支配"存在结构" | 只作用于现实存在之物；现实总量守恒，只能重新分配 |
| **虚无律** | 消除、否定、空缺 | 支配"抽象概念" | 只能操控抽象概念；定义总量守恒，只能转移或覆盖 |
| **精神律** | 意志即现实，认知决定形态 | 唯心·意志 | 只作用于有自主意识的对象；效果只存在于施术者认知世界；撤销即回退 |
| **信仰律** | 自身意志的坚信程度 | 唯心·自我 | 心证为凭；纯度要求（为信仰本身而信）；否定信仰会反噬 |
| **献祭律** | 等价交换，取舍之力 | 交换·等价 | 不能献祭不属于你的东西；价值对等；不可逆转 |
| **血脉律** | 溯源 | 溯源·继承 | 所有能力必须追溯到一个明确起始；觉醒后继承上级能力 |
| **污染律** | 侵蚀异化，腐化同源 | 扭曲·同化 | 同质化（把目标变成自身一部分）；扭曲（改变目标原有规则） |

> 备注：各律法细则详见 [[世界设定]] 下 [[七大律]] 各文件；[[精神律]]/[[信仰律]] 的"唯心"与 [[心之锁]] 的"唯心理想主义"同源，是"渡"这一母题的力量体现。

## 三、克制关系（双克制可叠加）

### 权柄克制链（律法层面）

```
因果律（隐性·不主动干涉，最高优先级）
        ↓
彼岸律 ←==→ 虚无律（对等互克，谁先出手谁占优）
        ↓
献祭律 → 污染律 → 血脉律 → 信仰律 → 精神律 → 献祭律（循环）
```

- 高阶律法对低阶律法有"权柄压制"——效果不可被低阶律法完全抵消。

### 属性克制环（能量层面）

```
炽 → 壁 → 彻 → 溟 → 噬 → 衍 → 炽
```

- 属性克制：伤害 +30%，效果成功率 +30%；被克则 -30%。

### 叠加结果

| 属性关系 | 权柄关系 | 结果 |
| :-- | :-- | :-- |
| 克制 | 克制 | **绝对支配**（伤害 ×3，不可抵抗） |
| 克制 | 被克 | 属性优势（+30%，权柄劣势部分抵消） |
| 被克 | 克制 | 权柄逆转（-30%，但可突破属性限制） |
| 被克 | 被克 | **绝对劣势**（×0.3，极大概率失败） |
| 对等 | 对等 | 纯粹对决（仅凭修为与技巧） |

## 六、三个关键推论

1. **力量 = 律法（规则）+ 属性（材料）+ 元素（形态）**，三者可自由组合 → 能力近乎无限，但被"八根律 + 六属性 + 克制链"锁死，不会失控。
2. **因果律是"裁判"不是"玩家"**：它不主动干涉，但"修改已发生的过去会被罚"，这保证了故事有"不可逆性"的重量感。
3. **律法的排斥性 → 每个强者都是一张"单牌"**：一个生灵只能兼容一个律法，团队战天然需要"律法互补"，这是组队 / 阵营 / 卡牌玩法的底层依据。
