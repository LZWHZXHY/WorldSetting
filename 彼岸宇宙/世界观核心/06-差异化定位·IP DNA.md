# 06 · 差异化定位 · IP DNA

> 目标是"做成米哈游那样的存在"，但**不是做第二个米哈游**。这一份回答一个最关键的问题：**凭什么"彼岸宇宙"不可替代？**

---

## 一、IP DNA（一句话）

> **用一个东亚神话的根（补天）、一套唯物的底层（间隙粒子）、一个存在论的哲学（位置），去讲"人凭什么超越自己的位置"。**

把它拆成五条"基因"：

| # | 基因 | 内容 | 为什么是护城河 |
| :-- | :-- | :-- | :-- |
| 1 | **单一物理底层** | 一切力量 = 间隙粒子（唯一材料）× 排列模式（规则）× 兼容性（资格） | 极端一致，无"作者说了算"的玄学感，有硬科幻的规则美感 |
| 2 | **位 / 渡 哲学母题** | 秩序（位）vs 意志（渡），渡必付价 | 是"存在论"不是"等级"，能承载深刻叙事，且东亚共鸣强 |
| 3 | **"补天"神话锚点** | 补天规则、补天者、补天序 | 女娲补天至今**未被任何大 IP 中心化**，是可独占的文化符号 |
| 4 | **工程化矩阵** | 律法 × 属性 × 元素 + 一元到十方 | 直接可落游戏/动画/卡牌，商业化转化成本极低 |
| 5 | **心之锁（人性力量）** | 唯心理想主义 + 代价 + 沉沦 | 情感钩子最强、最能出圈的"人类专属"设定 |

---

## 二、对标：和头部 IP 的差异点

### 1. 对米哈游（崩坏 / 原神 / 星穹铁道）

| 维度 | 米哈游 | 彼岸宇宙 |
| :-- | :-- | :-- |
| 世界观引擎 | 崩坏 / 终末 / 开拓，"为美好而战" | 位 / 渡 / 代价，"渡向彼岸" |
| 力量源 | 崩坏能 / 元素力 / 命途（相对开放） | 间隙粒子（单一、封闭、可量化） |
| 律 / 命途 | 开放增长，随剧情加 | **封闭的八根律（像元素周期表）** |
| 文化底色 | 多元文明拼贴 | 东亚"补天/位置"哲学为脊椎 |

> **结论**：米哈游的护城河是"工业化的内容产能 + 情绪叙事"；彼岸宇宙的差异化在**"一套可自洽到数值的世界观底层 + 一个未被占用的东亚哲学母题"**。不要学它"广撒多文明"，要学它"一个宇宙、多产品"的**结构**（见 [[07-孵化机制与创作守则]]）。

### 2. 对型月（Fate / 月姬 / 空之境界）

| 维度 | 型月 | 彼岸宇宙 |
| :-- | :-- | :-- |
| 力量源 | 根源 / 魔术 / 英灵 | 间隙粒子 / 虚能 / 补天规则 |
| 世界观情绪 | 神秘衰退、熵增、悲剧宿命 | **正向的"补天"**、超越而非衰退 |
| 设定风格 | 高度玄学、作者中心 | 高度规则化、可数值化 |

> **结论**：型月是"神秘终将消逝"的黄昏感；彼岸宇宙是"人偏要渡、渡则补天"的**黎明感**。同一个"规则魔法"的赛道，情绪方向相反，这就是差异。

### 3. 对 SCP / 克苏鲁系

| 维度 | SCP / 克苏鲁 | 彼岸宇宙 |
| :-- | :-- | :-- |
| 核心情绪 | 恐惧、收容、不可知 | 成长、超越、可规则化 |
| 神 | 不可名状、压倒性 | 可被"补"出来、可被理解与对抗 |

> **结论**：SCP 的"规则感"是恐怖；彼岸宇宙的"规则感"是**热血与宿命**。心之锁（困境中的人性突破）是正面回应——"神可以补出来，人也一样可以渡过去"。

## 三、三大护城河（为什么抄不走）

1. **底层物理唯一且硬核**：59.27%（渗流模型）这种细节，是"伪科学底座"的护城河——别人能抄"火球术"，抄不走"意识反向影响灵魂的 59.27% 阈值"这套世界观的**自洽感**。
2. **"位"作为哲学脊椎**：这不是力量等级，是存在论。一个世界观的"魂"一旦立起来，所有故事都会自动指向同一个母题，这是长线 IP 复利的来源（米哈游靠"为美好而战/开拓"复利，彼岸靠"位/渡/代价"复利）。
3. **"补天"神话的独占性**：女娲补天、精卫填海式的"逆天补缺"精神，是中国文化里最强的母题之一，且尚未被中心化。谁先把"补天"做成世界观级符号，谁就占住了这个文化位。

## 四、一句话风险提示

> **最大的风险不是"设定不够"，而是"设定太多、魂没立住"。**
> 彼岸宇宙目前最不缺细节（补天序已经非常工程化），最缺的是**一句话让外人记住的"魂"**——所以本核心把 [[02-母题与核心冲突]] 排在力量体系之前。先立魂，再填细节。
